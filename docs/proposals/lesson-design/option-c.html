Anatomy of a Good Prompt

A prompt is a brief. Four parts move the quality of an answer more than anything else. When output is bad, one of these is missing.

  • GoalThe outcome you want, not the topic. "Get them to confirm the date."
  • ContextWhat Claude can't know: who it's for, what happened, the constraints.
  • FormatThe shape: two paragraphs, a table, five bullets, subject plus body.
  • ExampleWhat "good" looks like. One example beats paragraphs of description.
Before you send: could a smart stranger act on this? If not, Claude can't either.

Do This Now

15 min

Run a bad prompt, then a good one, and feel the difference.

  1. Run the bad prompt. New chat, paste this exactly, read what comes back. 
    Write an email to my client about the delay.
  2. Write the better prompt. In a second new chat, ask for the same email using goal, context, format and example. Invent the situation if you need to. Paste a real email as the example if you have one.
  3. Compare side by side. Which one could you actually send? Which one sounds like you?
  4. Find the difference. Which single piece of context changed the result most? You'll write it down next.
