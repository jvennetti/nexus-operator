Anatomy of a Good Prompt

A prompt is a brief. When the output is bad, one of four parts is almost always missing.

GoalThe outcome, not the topic.
ContextWhat Claude can't know.
FormatThe shape of the answer.
ExampleWhat "good" looks like.

Before you send, ask: could a smart stranger act on this? If not, Claude can't either.

DO THIS NOW15 min

Run a bad prompt, then a good one, and feel the difference.

  1. Run the bad prompt. New chat, paste this exactly, read what comes back. 
    Write an email to my client about the delay.
  2. Write the better prompt. In a second new chat, ask for the same email using goal, context, format and example. Invent the situation if you need to. Paste a real email of yours as the example if you have one.
  3. Compare. Open both chats and read them back to back. Which one could you actually send?
  4. Name what made the difference. One sentence: the single piece of context that changed the result.

Still not sendable? Find the thin part, add it, run it again.
