Anatomy of a Good Prompt

A prompt is a brief. Most people write it the way they'd text a friend, then wonder why the output is generic.

GOAL · CONTEXT · FORMAT · EXAMPLE

Those four parts move quality more than anything else. When the output is bad, one of them is missing. Test any prompt with one question: could a smart stranger act on this?

DO THIS NOW 15 min
1
Run the bad prompt.
Open a new chat and paste this exactly. Read what comes back. It had no choice but to be generic. 
Write an email to my client about the delay.
2
Write the better prompt.
In a second new chat, ask for the same email using all four parts. Invent the situation if you need to: who the client is, what the delay is and why, what you want them to do next, how you sound. Paste a real email as the example if you have one.
3
Compare side by side.
Open both chats and read them back to back. Which one could you actually send? Which one sounds like you?
4
Write one sentence.
What single piece of context made the biggest difference? Put it in your . If the better prompt still wasn't sendable, find the thin part and run it again.
