## Brief

Two things keep you safe with Claude Code: the mode selector (Manual, Plan, Auto) and the habits you work with. This video shows three habits: work on a copy, keep an undo, and ask for a two-minute review. You'll make all three permanent.

## Challenge

Make the habits permanent.

1. Check nexus-workspace holds only copies. Keep one original of anything Claude edits, outside the folder.
2. Paste this and say yes. Then make a test change and paste "Undo the last change." Check it's gone.
```
Set up version history for this folder so I can undo any change.
```
3. After your next task, paste:
```
Two-minute review: tell me what you changed, what I should check first, and anything you're unsure about.
```
4. Paste:
```
Add a rule to CLAUDE.md: at the end of any task that changed files, give me a two-minute review.
```
5. When a chat gets long or confused, paste "Summarize what we did and where we left off," then start a new session with that summary.

Mark this done when the review rule is in CLAUDE.md and the undo works.

## Takeaways

- Copies, undo, review. Those three habits let you move faster later.
- Say yes to reading and creating new files. Read before you allow changes to files you already have. Say no to deleting anything you didn't ask for.
- Warning: Auto mode skips the asking. Earn it with the habits first.
- A long, confused session? Summarize it and start a new one.
