## Brief

Four habits keep Claude Code safe and sharp:

- **New task, new session.** Long sessions get slow and forgetful. The folder is the memory, so you lose nothing. To stop mid-task, ask for a HANDOFF.md.
- **Read permission prompts.** Allow a kind of action only once you trust it. Don't approve everything on day one.
- **Turn on version history.** Say "set up git and commit after each change." After that, "undo the last change" always works.
- **When it loops, stop.** Start a new session and state the goal fresh in one message.

## Task

Set up the safety habits once.

1. **Version history.** "Set up version history for this folder using git, and commit after each change you make from now on. Add that rule to CLAUDE.md."
2. **Test undo.** "Add a line to README.md that says 'test line.'" Then: "Undo that last change." Confirm it's gone.
3. **Practice the handoff.** Mid-task, say: "Write a HANDOFF.md with where we are and what's next." Start a new session and say: "Read HANDOFF.md and continue."
4. **Review your permissions.** Keep what you understand. Revoke anything you don't remember approving.
5. **Add the escape hatch to CLAUDE.md:** "If you try the same fix twice and it fails, stop and tell me what you've tried."

## Takeaways

- New task, new session. Use a HANDOFF.md to stop mid-task.
- Set up version history once. Then "undo the last change" always works.
- When it loops, stop and start clean.
