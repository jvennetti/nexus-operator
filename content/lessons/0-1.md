## Brief

This course runs inside Claude. Not alongside it, inside it. Every lesson ends with something you do in Claude, so before anything else, you need an account and the desktop app.

Two things to set up:

- **A Claude account** at claude.ai. The free plan is enough for the first three modules. Module 4 and beyond use Claude Code, which needs a paid plan (Pro or higher). You don't need to decide that today.
- **The Claude desktop app.** You can use Claude in the browser, but the desktop app is where Claude Code lives, and it's the one place you'll do everything in this course. Get it now so you never have to switch later.

If you already have both, use the skip button in the task box. It marks this lesson done and moves you on.

## Task

Get yourself online.

1. **Create your account.** Go to [claude.ai](https://claude.ai) and sign up with the email you actually use. Use your real name. Claude will learn to address you by it.
2. **Install the desktop app.** Download it from [claude.ai/download](https://claude.ai/download), install it, and sign in with the same account. Pin it to your dock or taskbar. You'll open it every day for the next few weeks.
3. **Send one message.** In the desktop app, start a new chat and type this exactly:
```
I just installed you. In two sentences, tell me what you can help me with today, then ask me one question about what I do.
```
4. **Answer the question it asks.** That's it. You're online.

> If anything in setup fails, tell Claude in the browser what happened. It will walk you through fixing it. That's a habit worth starting now.

## Takeaways

- The desktop app is your home base for this course. Chat lives there, and so does Claude Code.
- The free plan covers Modules 0 through 3. Claude Code (Module 4 onward) needs a paid plan.
- When something breaks, the first move is to tell Claude what happened.
