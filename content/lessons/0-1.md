## Brief

This course runs inside Claude. Not alongside it, inside it. Every lesson ends with something you do in Claude, so before anything else you need an account and the desktop app.

- **A Claude account.** The free plan is enough for the first three modules. Module 4 and beyond use Claude Code, which needs a paid plan. You don't need to decide that today.
- **The desktop app.** The video says the web version is plenty for occasional use. For this course it isn't: Claude Code lives in the desktop app, and it's the one place you'll do everything. Get it now so you never have to switch later.

Have your phone nearby. Signing up needs a real mobile number that can receive a text.

If you already have both, use the skip button in the task box. It marks this lesson done and moves you on.

## Task

Get yourself online.

1. **Create your account.** Type `claude.ai` into your browser's address bar yourself and sign up with the email you actually use. Use your real name. Claude will learn to address you by it.
2. **Install the desktop app.** Get it from [claude.com/download](https://claude.com/download) and nowhere else, install it, and sign in with the same account. Pin it to your dock or taskbar. You'll open it every day for the next few weeks.
3. **Send one message.** In the desktop app, start a new chat and type this exactly:
```
I just installed you. In two sentences, tell me what you can help me with today, then ask me one question about what I do.
```
4. **Answer the question it asks.** Then open claude.ai in your browser and check the same chat is there. One account, every device. You're online.

> If anything in setup fails, tell Claude in the browser what happened. It will walk you through fixing it. That's a habit worth starting now.

## Takeaways

- The desktop app is your home base for this course. Chat lives there, and so does Claude Code.
- Type the address yourself and download only from the official page. There is no "Claude Pro" program to download; Pro is a plan.
- The free plan covers Modules 0 through 3. Claude Code (Module 4 onward) needs a paid plan.
- When something breaks, the first move is to tell Claude what happened.
