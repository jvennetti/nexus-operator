## Brief

Every lesson in this course ends with something you do in Claude, so you need two things: a Claude account and the desktop app.

The free plan covers Modules 0 to 3. Claude Code, from Module 4 on, needs a paid plan (Pro or higher). You don't need to decide that today.

Use the desktop app, not the browser. It's where Claude Code lives, so you'll never have to switch.

Already set up? Use the skip button in the task box.

## Task

Get yourself online.

1. **Create your account** at [claude.ai](https://claude.ai) with the email you actually use.
2. **Install the desktop app** from [claude.ai/download](https://claude.ai/download) and sign in with the same account. Pin it to your dock or taskbar.
3. **Send one message.** In the desktop app, start a new chat and paste this:
```
I just installed you. In two sentences, tell me what you can help me with today, then ask me one question about what I do.
```
4. **Answer its question.** You're online.

> If setup fails, tell Claude in the browser what happened. It will walk you through the fix.

## Takeaways

- The desktop app is home base. Chat and Claude Code both live there.
- When something breaks, the first move is to tell Claude what happened.
