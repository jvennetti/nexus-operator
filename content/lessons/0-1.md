## Brief

This course happens inside Claude, so first you need an account and the desktop app. This video walks you through signing up and getting Claude on your computer. If you already have both, skip ahead.

## Challenge

Get Claude on your computer.

1. Go to [claude.ai](https://claude.ai) in your browser and sign up with the email you actually use. Have your phone nearby. It will text you a code.
2. Download the desktop app from [claude.com/download](https://claude.com/download), install it, and sign in with the same account.
3. Open the app, start a new chat, and paste this:
```
I just installed you. In two sentences, tell me what you can help me with today, then ask me one question about what I do.
```
4. Answer the question it asks you.

Mark this done when Claude has replied to you inside the desktop app.

## Takeaways

- The desktop app is home base for this course. Chat and Claude Code both live there.
- Only download Claude from claude.com. There is no "Claude Pro" program to install. Pro is a plan.
- The free plan covers Modules 0 to 3. Claude Code, from Module 4, needs a paid plan.
- Something broken? Tell Claude what happened. It will walk you through it.
