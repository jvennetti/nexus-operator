## Brief

Projects are where Claude keeps your instructions and files so you stop re-explaining. This video shows how to make a project, what should go in it, and how you can organize your work inside it.

## Challenge

Make the project you'll use for the rest of this school.

1. In the sidebar, click **Projects** → **Create new project** (or the **+** next to Projects). Name it **Nexus Academy**. [If it asks for a goal or description, write "my course work" and move on. Claude doesn't read that box.]
2. Open the project's instructions (look for **Instructions** or **Set project instructions**), paste this, and fill it in:
```
I'm [name]. I do [one line about your work]. Write in plain language. If a fact isn't in my files, ask me.
```
3. Add one real document to the project's files: something you refer to often, like a price list, a bio, a product description or a past proposal. (Look for **Files**, **Knowledge**, or the **+** on the right.)
4. Start a chat inside the project and ask a normal question about that document, without pasting it. For example: "What's our price for [thing]?" or "Summarize what this says about [topic]."
5. Find your "My tasks" chat in the sidebar and move it into the project (drag it in, or open its menu → **Move to project**).

Mark this done when Claude answers your question from the file without you pasting it.

## Takeaways

- Every chat in a project remembers your instructions and files, so you stop re-explaining.
- Catch yourself re-explaining something? Tell Claude to add it to the project instructions.
- A file you attach in a normal chat stays in that chat. Put it in the project if you want it every time.
- Suggestion: one project per job you do. It keeps your chats organized and your re-explaining to zero.
