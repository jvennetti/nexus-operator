## Brief

Now connect a tool you actually work in. This video shows Claude turning raw meeting notes into a finished Notion page, and how to give it access to only the parts you want. You'll do the same in your own tool.

## Challenge

Connect one work tool and let Claude do a real job in it.

1. Tell Claude you want to connect [your tool]. When it asks for permission, give it the smallest scope offered: one workspace, or one set of pages.
2. Paste this and check the answer matches what you allowed:
```
What can you see in [tool]?
```
3. Paste your notes from a real meeting or an email thread, then:
```
Create the tasks from this, assigned to me, with due dates where they're mentioned. Show me the list before you create anything.
```
4. When Claude asks permission to create, say yes once. Then open the tool and check what it made. Fix anything off by telling Claude.
5. Paste:
```
Give me a status summary of my open items.
```

Mark this done when something Claude created is sitting in your tool and looks right.

## Takeaways

- Give Claude the smallest access it needs. You can widen it later.
- "Show me before you create anything" is the habit. Check its work in the tool the first few times.
- The win is carrying information between tools by asking, instead of copying and pasting between tabs.
