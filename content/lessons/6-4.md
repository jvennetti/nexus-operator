## Brief

One last video, from someone who builds with Claude every day. It's the advanced version of what you've done: a written spec before building, a checker that grades the output, and a folder that gives Claude its context. You've already built a version of each.

## Challenge

Write your next system plan.

1. Watch with WORKFLOW.md open. Note one thing he does that you don't.
2. In the **Code** tab, paste:
```
Read WORKFLOW.md and RUN-LOG.md. Interview me about the next piece of my work worth building, and write NEXT.md: input, steps, output, destination, and what Version 1 does.
```
3. Paste this, then send the file to a friend. If they can't follow it, fix it.
```
Write SYSTEM.md: how to run my current system, written for someone who has never seen it.
```
4. Clean the workspace: delete test files, keep the originals outside.

Mark this done when a stranger could run your system from SYSTEM.md.

## Takeaways

- Spec, checker, context folder. That's the method, and you already have all three.
- Write it down for a stranger. If they can run it, it's a system.
- The next system starts the same way: pick, map, cut, build small.
