## Brief

A scheduled task runs on its own, on a cadence you set, so you wake up to the result. Schedule a skill or a prompt you've already run by hand at least twice, and start with tasks that draft rather than send. To set one up, finish a run that went well and say "schedule this to run every weekday at 7am."

## Task

Schedule something real and let it run.

1. **Pick the task:** your morning briefing from Module 3, or the skill from 5.1. Whichever you'd most like to find already done tomorrow.
2. **Run it by hand twice.** Fix anything off until the second run is exactly right.
3. **Make it draft, not send.** If it involves emails or messages, the instructions should say to draft them.
4. **Schedule it.** "Schedule this to run every weekday at [time], and deliver the result to [where you'll see it]."
5. **Check the first run.** Review the output and tell Claude what to change. Record how it went in your notes.

## Takeaways

- Schedule tested instructions, not vague prompts. Run it by hand twice first.
- Start with tasks that draft, not tasks that send.
