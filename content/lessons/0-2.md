## Brief

A quick tour so you know where things are before you need them. You're looking for five things: new chat, the sidebar (your chats and Projects), attaching files, Settings, and the Code tab. You don't need to understand them yet, just find them.

## Task

A scavenger hunt in the desktop app.

1. **Start a new chat** with a question you've actually wondered about this week.
2. **Attach a file.** Drag any document or screenshot into the message box and ask: "What is this, in one sentence?"
3. **Rename the chat** in the sidebar to something you'd recognize next week.
4. **Open Settings** and find your profile. If there's a place to tell Claude about yourself, write two sentences: what you do and what you want help with.
5. **Find the Code tab.** Don't start anything there yet. Go back to Chat.

## Takeaways

- Drag files into the message box. Claude reads documents, spreadsheets and screenshots.
- Chat is where you'll work until Module 4. Code is Claude Code.
