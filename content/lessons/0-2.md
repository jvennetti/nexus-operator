## Brief

Five minutes of orientation saves you hours of hunting later. The interface is simple, but a few parts of it matter for the course and most people never notice them.

What you're looking for:

- **New chat.** Every conversation starts here. You'll start many. Starting fresh is a skill, not a failure.
- **The sidebar.** Your chat history, and your Projects. Projects come up in Module 2. For now, just know they exist.
- **Attaching things.** The paperclip, or dragging a file straight into the message box. Documents, spreadsheets, screenshots, PDFs. Claude reads them all.
- **Settings.** Where your profile, connectors and preferences live. You'll be back here in Module 3.
- **Chat and Code.** The desktop app has two modes. Chat is where you'll live until Module 4. Code is Claude Code. Find it now so it isn't a mystery later.

You don't need to understand any of these yet. You need to know where they are.

## Task

A scavenger hunt. Find each of these in the desktop app and do the thing.

1. **Start a new chat** and give it a question you've actually been wondering about this week. Anything.
2. **Attach a file.** Drag any document or screenshot into the message box and ask Claude: "What is this, in one sentence?"
3. **Rename the chat.** Find the chat in the sidebar and give it a name you'd recognize next week.
4. **Open Settings.** Find your profile. If there's a place to tell Claude about yourself, write two sentences: what you do, and what you want help with. Save it.
5. **Find the Code tab.** Just find it. Don't start anything there yet. Go back to Chat.

Once you've done all five, mark the task done.

## Takeaways

- Attach files by dragging them into the message box. Claude reads documents, spreadsheets and screenshots.
- Your chats and Projects live in the sidebar. Rename chats you'll come back to.
- The desktop app has Chat and Code. You'll live in Chat until Module 4.
