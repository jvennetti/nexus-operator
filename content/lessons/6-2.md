## Brief

Build it. This video shows the loop: do the work by hand once, turn that into a lean skill, test it on past work Claude hasn't seen, and fix the skill in the smallest step. From here there are two tracks: a system that runs a workflow, or an app you use. You can do both.

## Challenge

Build Version 1.

1. Gather the last four or five times you did this work by hand: the input and your finished output. Keep two aside as the test pile. Don't show those to Claude yet.
2. Do one by hand with Claude until the result is right. Then paste:
```
Turn what we just did into a skill. Lean and minimal: every line must earn its place. It should apply to every [thing] of this kind, not just this one.
```
3. In a fresh session, paste this and save the result with the skill:
```
Here's the skill and three good past outputs. Write a 7-to-10 question yes/no checklist for judging a result.
```
4. Run the skill on the test pile only. Score each result with the checklist.
5. For every "no," paste:
```
Make the smallest change to the skill that fixes this. Show me exactly what changed.
```
6. App track instead? Same loop: build the simplest version in the Code tab with Plan mode, use it on real work, and fix it in the smallest step.

Mark this done when the test pile passes the checklist.

## Takeaways

- Do it by hand first. The skill is written from a run that worked.
- Test on work Claude hasn't seen, with a checklist you wrote before the test.
- Fix the skill in the smallest step, and read the change.
- Suggestion: build both tracks. The second one earns the OVERCLOCKED badge.
