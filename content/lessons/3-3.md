## Brief

Put it together. This video shows what goes into a good morning brief prompt: what Claude should read, what to ignore, and what to report back. You're going to write yours once and run it every morning this week.

## Challenge

Write your morning brief and run it.

1. Open a new chat in Nexus Academy and paste this:
```
Read my inbox since yesterday evening, my sent mail, and today's calendar. Read the full thread for anything from a client or about money. Then give me:
1. What needs a reply today
2. Anything with a deadline
3. Today's meetings, with a three-line prep for each
4. What I can ignore
Only use what's in the emails. If something is unclear, say so.
```
2. Read the brief. Spot-check one "needs a reply" item in Gmail: had you already replied?
3. Paste:
```
Draft replies to the quick ones, all in one message. Draft only.
```
4. Save your prompt somewhere you'll find it at 8 a.m. Run it tomorrow, and the day after. Fix one line each day based on what you didn't like.

Mark this done after three mornings.

## Takeaways

- One standing prompt, written once, beats four messages typed every morning.
- Tell Claude what to ignore as clearly as what to read.
- Your prompt is a living thing. Fix one line each time it annoys you.
- In Module 5 you'll make this run by itself.
