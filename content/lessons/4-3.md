## Brief

CLAUDE.md is a file Claude reads automatically at the start of every session in a folder. Think of it as an onboarding note for a new colleague. This short official video explains it. The idea is the same for your folder of documents.

## Challenge

Write your onboarding note.

1. In the **Code** tab, on nexus-workspace, paste:
```
Create a CLAUDE.md with: what this folder is for, where things go (reference files, outputs), and three rules for how you should work here: ask before changing an existing file, keep summaries under a page, and write in plain language. Keep it short.
```
2. Read it. Cut anything you wouldn't say to a new colleague.
3. Quit the app, reopen it on the folder, and give it a task that should trigger one of the rules, without mentioning the rule. Check it followed it.
4. The next time you correct Claude on something, paste:
```
Save that as a rule in CLAUDE.md.
```
5. End with:
```
Review CLAUDE.md and tell me what to simplify or remove.
```

Mark this done when Claude follows a rule you didn't repeat.

## Takeaways

- CLAUDE.md is read every session. Rules go there. Facts go in your reference files.
- Start small. Add a rule each time you correct Claude.
- Keep it short. A long CLAUDE.md gets ignored like a long email.
