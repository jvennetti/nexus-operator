## Brief

There's one file Claude Code treats specially. It's called `CLAUDE.md`, it sits at the top of your folder, and Claude reads it at the start of every session, automatically, before you say anything.

That makes it the most powerful file in the folder. It's where you put standing instructions. Not information (that's what the other files are for) but **rules and preferences.** How you want things done.

Things that belong in it:

- **How to write for you.** "Plain language. Short paragraphs. No corporate filler."
- **Where things go.** "Finished documents go in /output. Drafts stay in the project folder."
- **What to always do.** "Before creating a document, show me an outline and wait for my okay."
- **What to never do.** "Never delete files. Move them to /archive instead."
- **Your conventions.** "Date every file name like 2026-03-14. Use my templates in /reference."

It's the same idea as Project instructions in Chat, with one difference: it lives in the folder, so it travels with the work, and Claude Code can update it as you go. When you catch yourself telling it the same thing twice, say "add that to CLAUDE.md." You'll never say it a third time.

This is also the moment you'll start to understand what people mean by a **skill**. A skill is just a file of instructions for a specific task. `CLAUDE.md` is the general one. Module 5 is where you write the specific ones.

## Task

Write your instructions file, and then let it grow.

1. **Ask Claude to draft it.** In your workspace:
```
Create a CLAUDE.md for this workspace. Base it on ABOUT-ME.md and what you know about how I work. Cover: how I want things written, where finished work goes, what to always do before creating or changing files, what to never do, and any conventions for file names. Keep it short and direct. Show it to me before saving.
```
2. **Edit it.** Read every line. Cut what isn't true. Add the thing you keep saying. Make it yours.
3. **Test one rule.** Pick a rule from the file and give Claude a task that would trigger it. Confirm it follows the rule without being reminded.
4. **Teach it a new rule in the moment.** Next time you correct Claude ("no, shorter," "put that in output"), follow it with: "Add that to CLAUDE.md so I don't have to say it again." Check that it did.
5. **Read the file one more time** in your normal file browser. That's your operating manual. It will keep growing.

## Takeaways

- `CLAUDE.md` is read automatically at the start of every session. It's where standing instructions live.
- Rules and preferences go in `CLAUDE.md`. Information goes in other files.
- When you say something twice, say "add that to CLAUDE.md." Never say it a third time.
