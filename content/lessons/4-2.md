## Brief

Here is the most useful thing to understand about Claude Code, and it's not technical: **the folder is the memory.**

In Chat, context lives in the conversation and a Project. In Claude Code, context lives in files. Whatever is in the folder, Claude can read. Whatever Claude writes to the folder, stays. That means you can give it a permanent brain just by organizing a folder well.

What a good working folder looks like:

- **A note about you.** Who you are, what you do, how you like things. One file, read every time.
- **Reference material.** The docs you'd otherwise attach over and over. Brand voice, templates, examples, the client list.
- **Working areas.** A folder per project or client. Inside each: its own notes, its own files.
- **An output area.** Where finished things go, so you can find them.

You don't need to build this by hand. Claude Code will build it for you, and it will keep it tidy if you ask it to. Your job is to decide what belongs there.

Think of it as onboarding a new colleague by handing them a well-organized drive instead of explaining everything verbally. Every file you add is something you never have to say again.

## Task

Turn your workspace into a real working folder.

1. **Open `nexus-workspace` in Claude Code** and paste this:
```
I want to turn this folder into my working space with you. Interview me, a few questions at a time, about what I do, the kinds of projects or clients I work with, and what I'd like you to help with regularly. Then propose a folder structure for this workspace and create it. Include an ABOUT-ME.md file at the top that captures what you learned about me, written so that a future session can read it and know who I am.
```
2. **Answer the questions honestly.** This is the context everything else will use.
3. **Review the structure it proposes.** If something doesn't fit how you think, say so. Then let it create the folders.
4. **Move the reference material in.** Drag the documents you attach most often (templates, brand docs, examples) into the right folders. Then tell Claude: "I added some files. Look at them and add a REFERENCE.md that describes what each one is and when to use it."
5. **Test the memory.** Close Claude Code entirely. Open it again on the same folder. Ask: "Who am I and what do I do?" It should answer from the files, without you saying a word.

## Takeaways

- In Claude Code, the folder is the memory. Files in, context in. Files written, context kept.
- A good workspace has a note about you, reference material, working areas per project, and an output area.
- Let Claude build and maintain the structure. Your job is deciding what belongs there.
