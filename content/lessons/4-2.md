## Brief

Every chat starts from zero because nothing is stored where Claude can read it. The fix is a folder of plain text files. This short clip is someone explaining why that changed how he works. You're going to build yours.

## Challenge

Build the folder Claude remembers you by.

1. Write down the three things you re-explain most often: what you do, who your clients or projects are, how you like things written.
2. In the **Code** tab, on nexus-workspace, paste this and answer until it's done:
```
Interview me, one question at a time, and write what you learn into a file called ABOUT-ME.md: what I do, who I work with, and how I want answers written.
```
3. Copy the three files you attach most often into the folder, then paste:
```
I added some files. Look at them and write REFERENCE.md describing what each one is and when to use it.
```
4. Quit the app, reopen it on the same folder, and paste. It should answer from the files.
```
Tell me what you know about me.
```
5. Open ABOUT-ME.md yourself and change one fact. New session, ask again. The answer should use your edit.

Mark this done when Claude knows you in a fresh session.

## Takeaways

- Claude remembers what's in files, not what you said last week.
- ABOUT-ME.md and REFERENCE.md are your memory. Open them and edit them like any other file.
- Store a file once in the folder and you never attach it again.
