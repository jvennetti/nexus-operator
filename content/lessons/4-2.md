## Brief

In Claude Code, the folder is the memory. Whatever is in the folder, Claude can read. Whatever it writes there, stays. Organize the folder well and every session starts already knowing your work.

A good workspace has:

- **A note about you.** Who you are and how you like things.
- **Reference material.** Templates, brand docs, examples.
- **A folder per project,** with its own notes and files.
- **An output folder** for finished work.

You don't build this by hand. Claude Code builds and maintains it. You decide what belongs there.

## Task

Turn your workspace into a real working folder.

1. **Open `nexus-workspace` in Claude Code,** paste this, and answer its questions honestly:
```
I want to turn this folder into my working space with you. Interview me, a few questions at a time, about what I do, the kinds of projects or clients I work with, and what I'd like you to help with regularly. Then propose a folder structure for this workspace and create it. Include an ABOUT-ME.md file at the top that captures what you learned about me, written so that a future session can read it and know who I am.
```
2. **Review the structure** it proposes. Change what doesn't fit how you think, then let it create the folders.
3. **Move your reference material in:** the templates, brand docs and examples you attach most often. Then: "I added some files. Add a REFERENCE.md that describes what each one is and when to use it."
4. **Test the memory.** Close Claude Code, reopen it on the same folder, and ask: "Who am I and what do I do?" It should answer from the files.

## Takeaways

- The folder is the memory. Files in, context in. Files written, context kept.
- Let Claude build and maintain the structure. You decide what belongs there.
