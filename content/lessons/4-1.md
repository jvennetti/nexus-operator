## Brief

Chat answers questions. Claude Code acts: it can read, make and change files on your computer. This video shows the Code tab in the desktop app in under two minutes. One rule for this module: stay in Manual mode, so Claude asks before it changes anything.

## Challenge

Point Claude Code at a folder and ask it something.

1. Make a new folder on your computer called **nexus-workspace**. Put copies of two or three files in it. Copies, not originals.
2. In the desktop app, click the **Code** tab. In the chat box, click the folder button (it may say **Local** or **This computer**) → **Open folder** → pick nexus-workspace.
3. Under the chat box, find the mode selector and set it to **Manual**.
4. Paste:
```
What's in this folder? Describe each file in one line.
```
5. Then paste this, and say yes when it asks to create the file. Open the folder in Finder or Explorer and check the file is there.
```
Make a one-page summary of what this folder is for, as a new file called README.md.
```

Mark this done when README.md exists in your folder.

## Takeaways

- Chat can't change your files. Code can. That's the whole difference.
- Work on copies for now. Keep your originals outside the folder.
- Ask a question before asking for changes. "What's in this folder?" is the safest first move.
- Manual mode means Claude asks before it changes anything. Keep it there this module.
