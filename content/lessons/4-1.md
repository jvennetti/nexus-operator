## Brief

Everything so far happened in Chat. Claude answered, drafted, built things inside the conversation, and reached into your tools through connectors. Powerful, but every result still lives inside Claude. You copy it out.

**Claude Code** is the other half of the desktop app, and it flips that. Claude Code works inside a folder on your computer. It can read every file in that folder, create new ones, change them, organize them, and run things. It doesn't hand you a result to copy. It does the work where the work lives.

Despite the name, you don't need to write code or know what a terminal is. In the desktop app, Claude Code is a chat window pointed at a folder. You talk to it the same way you talk in Chat. The difference is what it can do with what you say.

A few things that make it different:

- **It sees your files.** Point it at a folder of documents and ask "what's in here?" It reads them all.
- **It does, rather than suggests.** "Rename these files by date." "Combine these notes into one document." "Build me a page that shows this spreadsheet as a chart." It makes the files.
- **It remembers through files.** What it writes down stays. Next session, it reads the folder and picks up where things were.
- **It asks before anything risky.** You'll see permission prompts. That's by design. Say yes to what you understand.

This module needs a paid Claude plan. If you're on the free plan, this is the moment to decide. Everything in Modules 4 through 6 is built here.

## Task

Open Claude Code and let it look around.

1. **Make a folder** somewhere easy to find. Call it `nexus-workspace`. Put three to five files in it: a couple of documents you've worked on, a spreadsheet, maybe a few images. Nothing precious. Copies are fine.
2. **Open the Code tab** in the Claude desktop app. When it asks for a folder, choose `nexus-workspace`.
3. **Ask it what's there.** "Look at everything in this folder and give me a one-line description of each file."
4. **Have it make something.** "Create a file called README.md that summarizes what this folder contains and what each file is for." Open the file in your normal file browser and read it. It's real.
5. **Have it change something.** "Rename each file so the name starts with today's date in YYYY-MM-DD format." Approve the permission prompt. Look at the folder. Then: "Undo that, put the names back." Watch it do it.

## Takeaways

- Chat answers. Claude Code acts, inside a folder on your computer, on real files.
- You don't need technical skills. It's a chat window pointed at a folder. Say what you want done.
- It asks permission before anything risky. Approve what you understand.
