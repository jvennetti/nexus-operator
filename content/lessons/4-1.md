## Brief

Chat answers; Claude Code acts. In the desktop app's Code tab, Claude works inside a folder on your computer, reading, creating and changing real files, and it asks before anything risky. You don't need to code: it's a chat window pointed at a folder, and from here on it needs a paid plan.

## Task

Open Claude Code and let it look around.

1. **Make a folder** called `nexus-workspace` and put three to five files in it: documents, a spreadsheet, a few images. Copies are fine.
2. **Open the Code tab** in the desktop app and choose `nexus-workspace` as the folder.
3. **Ask what's there.** "Look at everything in this folder and give me a one-line description of each file."
4. **Have it make something.** "Create a README.md that summarizes what this folder contains." Open the file in your normal file browser. It's real.
5. **Have it change something.** "Rename each file so it starts with today's date as YYYY-MM-DD." Approve the prompt and check the folder. Then: "Undo that, put the names back."

## Takeaways

- Chat answers. Claude Code acts on real files in a folder on your computer.
- It asks before anything risky. Approve what you understand.
