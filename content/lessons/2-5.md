## Brief

Claude can make things, not just text: documents, slides, charts, and small working tools you can use every day. This video shows Kevin building a dashboard and a tool just by describing them. You're going to build one you'll actually use.

## Challenge

Build a tool and use it this week.

1. Open a new chat inside Nexus Academy and paste this, filled in:
```
Build me a simple habit tracker as an artifact. Three habits: [habit 1], [habit 2], [habit 3]. One checkbox per habit per day for this week, a streak count for each habit, and a weekly percentage at the top. Keep it clean and easy to use.
```
2. Use it right away: tick today's boxes.
3. Change it twice. First in chat: "Add a one-line note for each day." Then by pointing at one part of it and asking for a change to just that part.
4. Close it, reopen it from the sidebar, and check your ticks are still there. If they're gone, paste:
```
Make it save my data so it's still there when I reopen it.
```
5. Open it every day this week. On day three, ask Claude for one change based on how you actually used it.

Mark this done when you've used the tracker three days running. [If Claude only ever answers in text, tell it you want code execution and file creation turned on. It will tell you where.]

## Takeaways

- Describe the thing you want in plain words and Claude builds it. Trackers, calculators, checklists, dashboards.
- Use it, then change it. The best tools come from a few rounds of real use.
- Ask Claude to make it save your data, and it will still be there tomorrow.
- Suggestion: anything you check every day is a candidate. Build the tool instead of keeping it in your head.
