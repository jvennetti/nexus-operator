## Brief

A skill is a set of instructions that Claude uses every time it does a specific task. This video shows you what skills are, and walks you through how to make one!

## Challenge

Turn something you do every week into a skill.

1. Pick a task you do the same way every week.
2. Do it once in a chat, the normal way, until the result is good.
3. Then paste this. Answer its questions and give it one example of a finished result you were happy with.
```
Use the skill creator to turn what we just did into a skill. Ask me anything you need.
```
4. Open a new chat and run it with just the trigger and fresh input:
```
Use my [skill name] skill on this:
```
5. If the result is off, fix the skill, not the answer:
```
Update the skill so it always [the thing it missed].
```

Mark this done when the skill works in a fresh chat with no extra explaining. [If Claude says it can't create skills, tell it you want code execution and file creation turned on. It will tell you where.]

## Takeaways

- A skill is just a text file with instructions that helps Claude do a specific task well.
- Give the skill creator your real material and examples to learn from.
- When the output is wrong, fix the skill, not the prompt.
- Warning: some skills from the internet hide malicious code. Have Claude check any skill before you install it. A skill you built yourself is safe.
