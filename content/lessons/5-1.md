## Brief

A skill is a text file of instructions for one specific task: when to use it, what to read, the steps, the output format, and what to check before finishing. `CLAUDE.md` covers how to work with you in general; a skill covers one recurring job, so "do the weekly report" becomes the whole prompt. The fastest way to write one is to do the task once with Claude, then say "turn what we just did into a skill."

## Task

Write your first skill from a task you already do.

1. **Pick a recurring task** from your Operator List, something you do weekly or more.
2. **Do it once with Claude** in your workspace, giving notes until the result is exactly what you'd want every time.
3. **Turn it into a skill,** then read the file and edit anything that's not how you'd describe it:
```
Turn what we just did into a skill file in a /skills folder. Include when to use it, what inputs to read, the steps, the exact output format with an example, and what to check before finishing. Then add a line to CLAUDE.md that says to use skills from /skills when a matching task comes up.
```
4. **Run it cold.** New session. Say only: "Do the [task name]." Compare it to the manual run. If something's off, fix the skill, not the prompt.

## Takeaways

- A skill is a text file of instructions for one task. No software involved.
- Do the task once, then say "turn that into a skill." When output is off, fix the skill.
