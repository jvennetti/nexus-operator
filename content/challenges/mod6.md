## Scenario

**What Runs Without You.** You chose a workflow, built Version 1, ran it for a week and wrote Version 2. This mission finishes it: Version 2 running, written up so a stranger could run it, and your next one planned. Two tracks: a system that runs a workflow, or an app you use. One earns OPERATOR. Both earn OVERCLOCKED.

## Steps

1. Build Version 2 from WORKFLOW.md and RUN-LOG.md. Run it on real work twice.
   Tip: if Version 2 wants to grow, ask what the smallest change is that fixes the most frequent mistake in the log. Do that one first.
2. Paste:
```
Write SYSTEM.md: how to run this, for someone who has never seen it. What it needs, what it does, what to check, and what to do when it breaks.
```
3. Send SYSTEM.md to one person and ask them to run it, or read it back to you. Every place they get stuck is a line to fix.
4. Clean nexus-workspace: test files gone, originals outside, CLAUDE.md and the Alone / Draft / Mine lines current.
5. Paste:
```
Read WORKFLOW.md, RUN-LOG.md and My Tasks. What should I build next, and why? Write NEXT.md with input, steps, output, destination, and what Version 1 does.
```
6. Second track, if you want it: built a system? Now build an app for yourself in the Code tab. Built an app? Now build a system. Same loop: plan, simplest version, use it, fix it in the smallest step.
   Warning: the second track is for when the first one is actually running. Two half-built things earn nothing.

## Deliverable

- Version 2 running on real work.
- SYSTEM.md a stranger could follow.
- A clean workspace and NEXT.md.
- Optional: the second track, for OVERCLOCKED.
