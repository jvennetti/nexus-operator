## Scenario

**The Trust Test.** Something you built is about to run without you. The question this mission answers is how much to let it do: what it may do alone, what it drafts for you, and what stays in your hands.

## Steps

1. Write a second skill, from another task you do the same way every week. Same loop as 5.1: do it by hand once, then use the skill creator, then run it cold.
2. Let your scheduled morning brief run three mornings in a row. Read every run.
   Warning: a green tick means the task ran, not that it was right. The output is the only thing that counts.
3. After the third run, answer three questions honestly: What did it get right every time? What did it get right only sometimes? What would have cost you if it had been wrong?
4. Turn the answers into three lines at the top of the task's instructions:
```
Alone: [what it may do without asking]
Draft: [what it prepares for me to approve]
Mine: [what it must never touch]
```
   Tip: when in doubt, put it under Draft. You can promote it later.
5. Paste the same three lines into CLAUDE.md in nexus-workspace, so Claude Code follows them too.

## Deliverable

- Two skills that work in a fresh chat.
- A scheduled task that has run three times and been read three times.
- Alone / Draft / Mine, written into the task and into CLAUDE.md.

## Note

Scheduled tasks need a paid plan. On the free plan, run the morning brief by hand three mornings. The trust decision is the same.
