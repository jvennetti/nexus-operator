## Scenario

You've written a skill, rescued a tired chat, and scheduled your morning brief. This mission is about trust: letting something you built run three times, then deciding what it's allowed to do alone.

## Steps

1. Write a second skill from another task you do the same way every week. Same method as 5.1: do it by hand once, then use the skill creator.
2. Let your scheduled morning brief run three mornings in a row. Read each run. Don't trust a green tick.
3. After the third run, decide three things and write them at the top of the task's instructions:
```
Alone: [what it may do without asking]
Draft: [what it prepares for me to approve]
Mine: [what it must never touch]
```
4. Paste the same three lines into CLAUDE.md in nexus-workspace, so Claude Code follows them too.

## Deliverable

- Two skills that work in a fresh chat.
- A scheduled task that has run three times and been read three times.
- The Alone / Draft / Mine lines in the task and in CLAUDE.md.

## Note

Scheduled tasks need a paid plan. If you're on the free plan, run the morning brief by hand three mornings; the trust decision is the same.
