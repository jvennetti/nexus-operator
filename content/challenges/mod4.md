## Scenario

**The Folder You Dread.** Every job has one: the monthly report built from six files, the inbox of attachments that needs sorting, the spreadsheet filled in by hand. This mission turns yours into a tool, and writes it down so someone else could run it.

## Steps

1. Name it. Which file job do you avoid? Copy the files it needs into nexus-workspace. Copies, never originals.
2. In the Code tab, switch to Plan mode and describe the job in one plain sentence. Add: "Ask me what you need to know first." Answer, read the plan, press Revise until you'd sign it, then Accept.
   Tip: cut anything in the plan you'll never use. A smaller tool that runs is worth more than a big one that doesn't.
3. Switch back to Manual and let it build. Run it on the real copies. Give three rounds of notes. Then give it bad input on purpose and say "fix it."
   Warning: say yes to reading and creating files. Read carefully before you allow a change to a file you already had.
4. Paste:
```
Write HOW-TO.md: how to run this tool, for someone who has never seen it. Include what to check afterwards and what to do when it breaks.
```
5. Ask for your two-minute review. If the review rule isn't in CLAUDE.md yet, add it now.

## Deliverable

- A working tool in nexus-workspace, run on real files.
- HOW-TO.md a stranger could follow.

## Extension

Paste: "Look at My Tasks. Which other task could be handled by something like what we just built?" Keep the answer for Module 6.
